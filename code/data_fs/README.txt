Feature-selection datasets
==========================

The datasets are public and are not redistributed in this package.

  python download_fs_datasets.py

writes them here as <Name>.csv (numeric features, class label in the last column).
Wine, WDBC and Digits are loaded directly through scikit-learn and need no file.

Expected files: Vehicle, Ionosphere, SPECTF, Sonar, Libras, HillValley, Musk1,
Semeion, Arrhythmia, Madelon (.csv).
Sources: UCI Machine Learning Repository (https://archive.ics.uci.edu) and
OpenML (https://www.openml.org).
