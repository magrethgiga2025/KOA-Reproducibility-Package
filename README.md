# KOA Reproducibility Package

This package contains source code and experimental outputs supporting the manuscript **“KOA: A State-Regulated Multi-Objective Evolutionary Algorithm With Archive-Guided Search and Geometry-Adaptive Survival.”**

## Contents

- `code/` — experiment, analysis, sensitivity, ablation, convergence, and runtime scripts.
- `code/algorithms/koa_final_v3.py` — KOA implementation selected by the experiment factory for `KOA`.
- `code/algorithms/factory.py` — constructs KOA and the six comparison algorithms.
- `code/problems/` — custom LSMOP and MaF problem implementations/support.
- `code/utils/` — metrics, statistics, initialization, and supporting utilities.
- `results/` — raw and processed experimental results.
- `requirements.txt` — Python dependencies supplied with the experiment code.

## Main experiment

The configuration in `code/config.py` specifies:

- Population size: 100
- Archive capacity: 120
- Generations: 300
- Independent runs: 30
- Random seeds: 1–30
- Algorithms: KOA, NSGA-II, NSGA-III, MOEA/D, RVEA, AGE-MOEA2, and CMOPSO
- Benchmark problems: ZDT1, ZDT2, ZDT3, DTLZ1, DTLZ2, DTLZ4, DTLZ6, DTLZ7, WFG1, WFG4, WFG6, WFG9, LSMOP1, LSMOP9, MaF4, and MaF7.

`results/raw_runs.csv` contains the run-level outputs for the main experiment.

## Many-objective experiment

`results/many_objective_raw.csv` is the corrected raw-results file supplied for the many-objective evaluation. It is retained separately from the main 16-problem experiment.

## Other supporting results

The results directory also contains summary tables, Wilcoxon-test outputs, Friedman rankings, convergence trajectories, runtime results, ablation results, factorial-ablation results, parameter-sensitivity results, and diagnostic outputs generated during the study.

## Reproduction

Create a Python environment and install the supplied dependencies:

```bash
pip install -r requirements.txt
```

Run commands from the `code/` directory so local `algorithms`, `problems`, and `utils` modules are importable. The principal experiment runner is:

```bash
python run_experiments.py
```

Additional scripts in `code/` reproduce the corresponding runtime, convergence, ablation, sensitivity, diagnostic, and many-objective analyses. Review each script before execution for its command-line options and output paths.

## Data provenance

The benchmark problems are synthetic multi-objective optimization functions. The deposited CSV files are computational outputs generated by running KOA and the comparison algorithms under the experimental configurations encoded in the supplied scripts.

## Notes

Development/obsolete KOA variants present in the original working archive were intentionally excluded from this clean package. The experiment factory in the supplied code imports `KOAFinalV3` from `algorithms/koa_final_v3.py` when the algorithm name is `KOA`.

No repository DOI is included in this package. Add the DOI or persistent identifier to the manuscript Data Availability Statement after depositing this package in the repository selected for publication.

## Biological inspiration

KOA is conceptually inspired by the Kipunji (*Rungwecebus kipunji*), a primate endemic to Tanzania. The biological literature motivating the algorithm is cited in the associated manuscript and is not redistributed in this repository.

The biological inspiration provides conceptual motivation for the balance between localized exploitation of previously productive regions and broader exploratory movement. It should not be interpreted as a direct mathematical simulation of Kipunji behaviour. The optimization mechanisms implemented in KOA are computational operators whose performance is evaluated using the benchmark experiments and data provided in this repository.
